# 未来からの手紙｜仕様 v0.2（2026-10-31・オーナー決定）

## 決定した仕様（オーナー 2026-10-31）
| | 内容 | 実装 |
|---|---|---|
| ① 書く日 | Day 1 | Day 01 の「夜のふりかえり」に折りたたみ（任意） |
| ② 届く日 | Day 7・14・21 | 各日の「夜のふりかえり」の最初に表示 |
| ③ 未来の設定 | 21日間を歩き終えた未来の自分 | 誘導文で設定 |
| ④ 封 | Day 1 で書き終えたら封を閉じる。Day 7 で初めて開封できる。読まずに取っておける。一度開封したら、いつでも読み返せる | 「書き終えたら、封を閉じる」（画面内で確認）。封のあとは中身を出さず書き換え不可。Day 7・14・21 で「封を開ける／今は読まずに取っておく」。開封後は「手紙を読む」と手紙の画面でいつでも読める |
| ⑤ 文言 | 導入「答えから、今を見てみましょう」と誘導文（オーナー原文） | 原文のまま（一字一句をテストで確認） |
| 開封時 | 「未来のあなたから、手紙が届いています。」 | そのまま |
| 開封後 | その日の自分が感じたことを記録 | 「手紙を読んで、今日のあなたが感じたこと（任意）」を日ごとに保存 |
| 保存 | 端末内・バックアップ・復元 | 封・開封の日時も含めて保存・復元 |
| 以前の形式 | 削除せず区別して保存 | 「以前の形式で書いた手紙（21日後の自分へ）」として別に保存・別枠で表示 |

## 補足（実装上の判断）
- このアプリはどの日からでも開ける設計（仕様書 v0.6）。そのため「Day 7 で開封」は **Day 07 の画面で開けられる**という意味で実装した。日付（封から7日後など）で鍵をかけることもできるが、未決定のため入れていない。
- 封を閉じる前の手紙は「書きかけ」。Day 07 には届かない。
- 以前の試作版（10/31 午前）で書いた封の無い「未来からの手紙」は、書きかけとして Day 01 に戻る（公開していないため、該当者はほぼいない見込み）。
- 文言のうち、私が足した短い案内（オーナー確認待ち）：「書き終えたら、封を閉じてください。封を閉じた手紙は、Day 07 に届きます。書かなくてもかまいません。」／封の確認「封を閉じると、Day 07 まで開けられません。書き直しもできなくなります。」／「封を開けるかどうかは、あなたが選べます。読まずに取っておくこともできます。」／「一度開けた手紙は、いつでも読み返せます。」

## 設計案 v0.1（2026-10-31・暫定）

**状態：暫定実装済み・未承認。** 教材 `content/days.yellow.json` v0.8 は変更していない。

## 1. 何の手紙か（オーナー訂正）
- **未来の自分から、今の自分に届く手紙。**
- 書き手は受講者本人。ただし「未来のあなた」になったつもりで、「今のあなた」へ宛てて書く。
- 以前の試作「21日後の私へ」（今の自分 → 未来の自分）は宛先と時間の向きが逆だったため、作り直した。

## 2. 体験の流れ（いまの実装）
| 場面 | 画面 | 文言（暫定） |
|---|---|---|
| 書く：Day 01 の夜のふりかえり | 折りたたみ「未来からの手紙（任意）」。開くまで本文欄は見えない | 「未来のあなたは、今のあなたに何を伝えたいでしょう。」（オーナー暫定案）<br>「21日を歩いた先のあなたになったつもりで、今日のあなたへ書いてみましょう。書かなくてもかまいません。この手紙は、Day 07・14・21 に、読みたいときだけ読み返せます。」<br>入力欄の薄い見本：「今のあなたへ。」（保存はされない） |
| 届く：Day 07・14・21 の夜のふりかえり | 「手紙を読む／今は読まない」を本人が選ぶ。選ぶまで中身は出ない | 「未来のあなたから、手紙が届いています」「読むかどうかは、あなたが選べます。」 |
| 読む | 手紙の本文と、書いた日付 | 「〇年〇月〇日、未来のあなたになって書いた手紙」 |
| 応える（任意） | 一言の欄 | 「手紙を受け取った今のあなたから、ひとこと（任意）」 |
| いつでも見返す | 「私の発見」→「未来からの手紙」（`#/letter`） | 手紙と、各日のひとことを並べる。評価・比較の言葉は付けない |

- 手紙を書いていない人には、Day 07・14・21 でも何も表示しない（書かなかったことを責めない）。
- 「今は読まない」を選んでも、あとからいつでも読める。
- 端末内だけに保存。外部へ送らない。通知はしない。バックアップ・全削除の対象。

## 3. 決めていただきたいこと（オーナー）
1. **書く日**：Day 01（いまの実装）／別の日（例：Day 07 や Day 14）／いつでも書ける
2. **届く日**：Day 07・14・21（いまの実装）／Day 21 だけ／書いた翌朝に一度だけ届く
3. **未来の「いつ」**：21日を歩いた先（いまの実装）／1年後／「少し先」とだけ書く
4. **書いた直後に読めるか**：いまは Day 01 でそのまま読み直し・書き直しができる。届く日まで閉じておく（封をする）演出にするか
5. **文言**：上の表の暫定文言でよいか。誘導文（どう書くか）を足すか
6. **黄金の心との関係**：インナービジョンで同じ手紙をどう扱うか（21日間の画面には出さない）

## 4. データと互換
- 新しい項目：`futureLetter`（手紙）・`futureReplies`（届いた日のひとこと）・`futureSkipped`（今は読まない）
- 以前の試作の項目 `letter`・`letterReplies` は、**消さずに残す**。未来からの手紙としては扱わず、手紙の画面の「以前の形式で書いた手紙（21日後の自分へ）」の折りたたみで読めるだけにした。以前の試作は公開していないため、実際に該当する記録はほぼ無い見込み。
- 以前の試作の「今は読まない」（`letterSkipped`）は、宛先が違うため引き継がない。
- バックアップは同じ形式（schema 1）のまま。古いバックアップも読み込める（テストで確認）。
