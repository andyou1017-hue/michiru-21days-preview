# iPhone Safari での確認手順（オーナー・確認担当向け）

所要：40〜50分。**本物の個人的な内容は書かず、「テスト」などの文字で確かめてください。**

## 準備
- 確認したい版を開く
  - いま公開中の版（3つの新機能の前）：https://andyou1017-hue.github.io/michiru-21days-preview/
  - **PR #1 の新機能（今日の扉・私の発見・未来からの手紙）の確認用ページ**：URL はオーナーに直接お伝えしています（このリポジトリは誰でも読めるため、ここには書きません）。検索結果には出ない設定で、画面の上に「iPhone確認用・最終承認前」と出ます。リンクを他の人に送らないでください。
  - 確認用ページは、main に統合したとき（自動の公開）に消えます。
- **Safari** で開く（LINE などのアプリ内ブラウザではなく）。
- プライベートブラウズは使わない（閉じると記録が消えるため）。

## 確認すること（結果を ○／× と、× ならその画面のスクリーンショット）
| # | 操作 | 期待すること |
|---|---|---|
| 1 | 開く → 「上の内容を読みました」にチェック → 「はじめる」 | 21日の一覧が出る。文字が読みやすい大きさ |
| 2 | 画面を上下に送る | 左右にずれない。下のメニュー（21日・記録・発見・設定）が隠れない |
| 3 | 「今日の扉をひらく」 | 1回のタップで Day 01 の「朝の気分」へ |
| 4 | 気分のつまみを左右に動かす | 数字が変わる。良い・悪いの言葉は出ない |
| 5 | 気分の欄の上を指でなぞって画面を送る | 気分が勝手に記録されない（「未記録」のまま） |
| 6 | 「次へ」→ 33秒「はじめる」 | 数字が減り、11秒ごとに案内が変わる |
| 7 | 10秒ほどで「一時停止」→ 少し待つ →「再開」 | 止めている間は減らない |
| 8 | 33秒の途中で画面を消す（電源ボタン）→ 数秒後に戻る | 消していた時間も含めて進んでいる。止まったり壊れたりしない |
| 9 | 問いの欄をタップ | 画面が勝手に拡大しない。キーボードで入力欄が隠れない |
| 10 | 日本語・絵文字・改行を入れて「次へ」「戻る」 | 入れた文字が残っている |
| 11 | Safari を完全に閉じる（アプリ切替画面で上にスワイプ）→ 開き直す | 記録が残っている。「今日の扉」が前回の日を指す |
| 12 | 夜のふりかえり →「この日を完了にする」→ 一覧へ | Day 01 に「✓ 完了」 |
| 13 | 「完了を取り消す」 | 未完了に戻る。記録は残る |
| 14 | 設定 → 文字の大きさ「特大」 | 全体が大きくなり、左右にはみ出さない |
| 15 | 設定 →「記録をファイルに保存」 | ファイルの保存先（「ファイル」アプリ）を選べる。保存できる |
| 16 | 設定 →「すべての記録を削除」→ 確認で「すべて削除する」 | 最初の画面に戻る |
| 17 | 設定 →「ファイルから記録を戻す」→ 15 のファイルを選ぶ | 件数の確認が出る →「置き換える」で記録が戻る |
| 18 | （確認用ページ）Day 01 の夜 →「未来からの手紙」を開く →「感謝の瞑想（約1分）」 | 案内が15秒ごとに変わる。終わると書く欄が出る。途中で画面を消しても進みが合う |
| 19 | （確認用ページ）手紙を書く →「書き終えたら、封を閉じる」→ 確認で「封を閉じる」 | 「封をしました」。中身は見えない |
| 20 | （確認用ページ）Day 07 の夜を開く →「今は読まずに取っておく」→ Day 14 の夜 →「封を開ける」 | 「未来のあなたから、手紙が届いています。」。開けると手紙と「感じたこと」の欄 |
| 21 | （確認用ページ）夜のふりかえりで「私の発見に残す」→ 下の「発見」 | 残した言葉が出る |
| 22 | （確認用ページ）トップの「今日の扉をひらく」 | 前回の日（完了していれば次の日）が開く |
| 23 | 設定 → アクセシビリティ → VoiceOver をオンにして一覧と Day 01 をなぞる | ボタンや欄の名前が読み上げられる（任意） |

## 結果の送り方
PR #1 にコメントするか、チャットで「#8 が ×」のように番号と、スクリーンショットを送ってください。iPhone の機種と iOS のバージョン（設定 → 一般 → 情報）も添えてください。
