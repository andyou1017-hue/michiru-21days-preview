# iPhone Safari での確認手順（オーナー・確認担当向け）

所要：40〜50分。**本物の個人的な内容は書かず、「テスト」などの文字で確かめてください。**

## 現在の状況（2026-11-02）

**招待制HTTPSの受講生向け本番URLはまだありません。iPhone Safari実機試験は未実施です。**
既存のGitHub Pagesは公開プレビューであり、招待認証・サーバー保存・サーバー時刻による7日制限を検証する場所ではありません。プレビューには本名・実際の記録・未来からの手紙を入力しないでください。

## 準備

- **招待制の検証**：最終承認前に隔離したHTTPS検証環境を用意できた場合のみ、架空の受講生アカウント・テスト用招待コードで行う。現在そのURL・実機結果は未確認。
- **公開プレビューの見た目確認のみ**：既存の公開プレビューは最新Draft PR #10とは異なる可能性がある。公開プレビューの合格を招待制版の合格として扱わない。
- iPhone本体のSafariで開く。LINE等のアプリ内ブラウザではないことを確認する。
- iOSバージョン、機種、試験日時、対象URLの種類（公開プレビュー／招待制検証）を記録する。
- プライベートブラウズは使わない。テストデータだけを使い、実際の受講生情報を使わない。
- 招待制検証環境がない間は、認証・端末間同期・サーバー側7日制限・本番HTTPSを**未確認**と記録する。

## 結果の記録
PR #10 の確認記録に、対象版・iPhone機種・iOSバージョン・実施日時と、各番号の ○／×／未確認 を残す。× の場合は個人情報を含まない画面だけを添付する。**WebKitの自動テスト結果を実機Safari合格に読み替えない。**

特に招待制検証版では、未招待拒否、別端末での記録再表示、封印後7日未満の開封拒否（端末時計を進めても不可）、7日経過後の開封、ログアウト後の保護、Safari終了・再起動時の記録保護を別途確認する。7日後の実確認ができるまではその項目を未確認とする。
