# 2026-11-01 06時台｜未来からの手紙：サーバー側7日ロック（API第1段階）

## 実装範囲（Draft PR #2、未公開）
- `runtime/gateway.js` にアカウント別の `future_letters` テーブルを追加。
- `POST /api/future-letter/seal` は本文を1度だけ保存し、サーバー時計で封印日時を確定。封印後の上書きは409で拒否。
- `GET /api/future-letter/status` は封印日時・解禁日時・状態だけを返し、本文を返さない。
- `POST /api/future-letter/open` は封印から7日未満は423、7日経過後のみ本文を返す。
- 他人のアカウントの手紙は取得不可。アカウント削除時には手紙本文もDBから削除。
- `GET /api/bootstrap` は封印した手紙を返さない。端末時計の変更やバックアップ改変でサーバーの解禁時刻は変わらない。
- `tests/letter-lock.test.js` に境界時刻（7日-1ms/7日）、未認証、別利用者、再封印、削除、Origin拒否を追加。
