# 満ちる眼：専用引き継ぎと分離ルール（暫定）

## 適用範囲
このリポジトリは「満ちる眼｜在るを生きる21日間」受講生アプリ専用。天命羅針の占術、鑑定、占い商品、コード、画像を持ち込まない。公式サイト等の別リポジトリも勝手に編集しない。

## 守る中心思想（会話からの整理。逐語原本ではない）
- 主軸は「在る」「ワンネス」「美点発見」。心理学・脳科学は補助説明にとどめる。
- 21日間は初めての人向けに黄色の心を入口とし、それ自体で完結する価値を持つ。次段階のインナービジョンでは同じワークを黄金の心から取り組む。21日アプリに次段階の体感を混入させない。
- ワークの前に短く納得できるミニ解説を置く。説教的・不自然な言葉を避け、温かな丁寧語にする。
- 毎日の美点発見、今の気分、感謝、内観、未来からの手紙、日常の行動を大切にする。
- 33秒の時間は、呼吸を整え脈・心臓の音に意識を向ける「命の瞑想」への変更希望がある。医療効果を断定しない。
- Day1で未来からの手紙を書き、Day7/14/21に届ける構想。封を閉じた場合の編集不可・開封制限など、仕様と実装を照合する。
- デザインはクリームから陽だまりの黄色、柔らかな余白、毎日違う21種の花。スマートフォン、とくにiPhone Safariで読みやすくする。
- 招待受講生だけが利用できる配布方式を目指す。単なる公開URLや端末内保存だけでは招待制を満たさない。

## 保存と実装のルール
1. 原稿・既存教材・デザインを無断で上書きしない。原文、整理メモ、未承認提案を分離する。
2. このファイルはチャット全文でも画像原本でもない。完全移行と表現しない。
3. 本リポジトリの実装と正式原本を照合し、欠落、仮仕様、未実装を明示する。
4. 変更は独立ブランチとPRでレビュー。既存の別リポジトリ「michiru-eye」には触れない。
5. 天命羅針とのデータ・コード・教材の相互流用を禁止。
6. 受講生への正式公開はユーザーの最終確認後。
