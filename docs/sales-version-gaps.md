## 販売版の仕組みの現状
Claude Code が 2026-10-30 に、別の作業フォルダで販売版のサーバーを試作し、テストした（40件合格、うちサーバー関連13件）。
**ただし GitHub のどこにも保存していない。** このクラウドの作業環境は一定時間で消えるため、残すには**非公開のリポジトリ**が必要（オーナーに作成をお願いする）。公開リポジトリには、セキュリティ上も入れない。
