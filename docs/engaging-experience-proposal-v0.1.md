# 満ちる眼｜21日間 続けたくなる体験改善案 v0.1

状態: **提案・未承認**。既存の教材原稿 `content/days.yellow.json`、公開中のアプリ、保護対象の他リポジトリには変更を加えない。

## 目的
「頑張って連続ログインする」ではなく、「明日も自分の心に会いたくなる」静かな体験。21日間は単独で完結し、強制的な継続・課金誘導・他人との比較はしない。

## 優先する実装 3件

### P1 今日の扉
- ホームの最上部に「Day N / 21」「今日のひとこと」「今日の扉をひらく」を配置。
- 既存の日別本文は書き換えず、扉の導入文は別のUIコピーとして管理。
- 未完了日があっても翌日続けられる。未来日の本文を隠すかどうかはユーザー確認まで保留（閉鎖・有料ロックはしない）。
- 画面読み上げ、キーボード操作、小画面を維持。

### P2 私の発見
- 各日の回答から、自分で「残したい一言」を任意で保存できる一覧。
- 数値スコア、他者順位、連続記録の罰則は作らない。
- 全情報は現行の端末内保存方針を厳守。既存のバックアップ・消去・エクスポートの対象に含めること。
- まずテキスト中心で実装し、種・葉などの飾りは後回しにする。

### P3 過去の自分からの手紙
- Day1に「21日後の私へ」を任意で記入。Day7/14/21に、本人の同意操作で過去の記録を再表示。
- 自動通知・メール・外部サーバー送信は行わない。
- 過去の言葉は編集前の引用と現在の気づきを並べる。比較を評価としない。
- つらくなる場合は「今は読まない」を選択できる。

## 正式教材・世界観のガードレール
- 「在る」「ワンネス」「美点発見」が中心。心理学的な効果の断定はしない。
- 黄色の心を入口とし、黄金の心で同じ問いに触れるインナービジョンへ自然に接続する。
- 21日間完了者への面談は希望制・一度のみ。受講や登録を強要しない。
- 33秒瞑想の原稿は仮のため、本人承認まで変更しない。
- `michiru-eye` 等の他リポジトリは一切変更しない。

## 受け入れ基準
- 利用者が起動後ワンタップで今日のワークに入れる。
- 本人が望む一言だけ一覧に残せる。
- Day1に残した手紙を本人の任意操作で振り返れる。
- 未実施・未入力・途中中断でも罪悪感を与える表現がない。
- データが第三者へ送られない。
- 原稿 v0.8 の内容と既存の保存記録を保持する。
