# 満ちる眼｜在るを生きる21日間（試作版プレビュー）

**最終承認前の試作版です。** 教材は「受講者用原稿候補 v0.8」（原本照合中）を使っています。

- プレビュー：https://andyou1017-hue.github.io/michiru-21days-preview/
- ログインなし。書いた記録は**開いた人の端末のブラウザの中だけ**に保存され、運営者を含め誰にも送信されません。
- 治療・診断を目的としません。

## できること
今日の扉（ホームから1タップで今日のワークへ）／私の発見（自分で選んだ一言だけを残す一覧）／21日後の私への手紙（Day1に書き、Day7・14・21で読みたいときだけ開く）／21日分の教材／33秒の静かな時間（一時停止・再開・とばす）／朝夕の気分（0〜10・任意）／ワークの記入／今日の行動／進捗の自動保存／完了の取り消し／Day5とDay20の比較／バックアップ（ファイルに保存・戻す）／日ごとの削除・全削除／文字サイズ4段階／スマホ縦画面（幅320pxまで）・キーボード操作

## このリポジトリについて
- 公開してよいもの（受講者に見せる教材と画面）だけを置いています。教材の出典・講師向けのメモ、購入者ログイン・決済などの本番用の仕組みは、ここには置いていません。
- `main` に保存すると、自動でテストを行い、合格したら `gh-pages` ブランチを更新してプレビューに反映します（`.github/workflows/test-and-deploy.yml`）。

## 手元で動かす
```
npm start            # http://127.0.0.1:8340/
npm test             # ブラウザのテストには playwright が必要（npm i --no-save playwright）
```
教材を直したら `content/days.yellow.json` を編集し、`npm run build:content`。
